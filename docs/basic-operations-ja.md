# 基本操作と困ったときの確認

このページは、CrossPoint Yomuka の日常的な操作と、不具合を報告する前に安全に確認できる項目をまとめたものです。

端末のボタン割り当て、画面の向き、テーマによって物理ボタンの役割は変わることがあります。**画面下部に表示される操作名**（戻る、決定、前、次など）を基準に操作してください。

## まず覚えておく操作

### スリープと電源

- 電源ボタンを長押しすると、端末はスリープに入ります。
- 設定によっては短押しの動作が変更されています。意図しない動作を避けるため、設定が不明なときは長押しを使ってください。
- スリープ画面に表示が残っていても、電子ペーパーの特性上、それだけで端末が動作し続けているとは限りません。

### 完全に再起動する

画面が固まった、または更新状態を最初から確認したい場合は、次の順で再起動できます。

1. 側面の **Reset** ボタンを一度押して離します。
2. すぐに **Power** ボタンを数秒長押しします。
3. 起動画面が表示されるまで待ちます。

再起動では、SD カード内の書籍は削除されません。通常は最後に読んでいた書籍が開きます。

> [!CAUTION]
> ファームウェア更新中、SD カードへの書き込み中、またはキャッシュ生成中には Reset を押さないでください。

## 設定画面の操作

ホーム画面から **設定** を開くと、画面上部にカテゴリ、下に設定項目が表示されます。現在選ばれている場所は反転表示されます。

### カテゴリを選ぶ

- 最初は上部のカテゴリが選ばれています。
- 画面に **上**／**下** と表示されるボタンで、`表示`、`読書`、`操作`、`本体` を切り替えます。X3 では `RTC設定` も表示されます。
- **決定** を押しても、次のカテゴリへ移動できます。

### 項目を選び、値を変える

1. 画面に **左**／**右** と表示されるボタンで、設定項目へ移動します。
2. 値を変えられる項目では、**決定** を押して編集状態に入ります。
3. 編集中に **左**／**右** で値を変更します。
4. **決定** または **戻る** で編集を終えます。

`Wi-Fiネットワーク`、`読書キャッシュを消去`、`縦書き設定` のように別画面を開く項目は、選んで **決定** すると次の画面へ進みます。

### 戻る・保存する

- 項目を選んでいるときに **戻る** を押すと、カテゴリ選択へ戻ります。
- カテゴリ選択中に **戻る** を押すと、設定画面を閉じます。
- 変更した値はすぐ反映され、設定画面を閉じると保存されます。

> [!TIP]
> ボタンの割り当てを変更している場合も、画面下部の操作表示に従ってください。分からなくなったときは、**操作** カテゴリの `フロントボタンを割り当て` から既定の役割を確認できます。

## 表示に関する設定

### ダークモードを確認する

1. **設定** を開きます。
2. **表示** カテゴリを選びます。
3. **カラーモード** を選び、`ライト` または `ダーク` を確認・変更します。

ダークモードの切り替えはすぐ画面に反映されます。表示不具合を比べるときは、現在の値をメモしてから反対の値で同じ操作を一度だけ試してください。

### スリープ画面を確認する

1. **設定** → **表示** を開きます。
2. **スリープ画面** を選びます。
3. `ダーク`、`ライト`、`カスタム`、`カバー` など、現在選ばれている値を確認します。

ゴーストを報告するときは、読書画面の背景（白／黒）と、スリープ画面の設定（ライト／ダーク）を一緒に伝えてください。

## 画面のゴーストが気になるとき

### XTC を読んでいる場合

1. 読書中に、画面下部で **決定** と表示されているボタンを押して読書メニューを開きます。
2. **画面を更新** を選びます。
3. 決定して、表示が改善したか確認します。

この操作は表示を清掃するためのものです。書籍、しおり、読書位置、表示設定は削除しません。

### EPUB を読んでいる場合

EPUB の読書メニューには、現在は `画面を更新` の項目がありません。無理にキャッシュ削除や初期化を行わず、次の情報を記録してください。

- ゴーストが出た画面の写真
- 読書画面が白背景か黒背景か
- 直前に変えた設定
- 画像があるページの直後か
- スリープ画面でも残るか

## キャッシュを消す前に

**設定** → **本体** → **読書キャッシュを消去** は、すべての読書キャッシュと読書進捗を削除します。書籍ファイル自体は削除されませんが、次に開くと再インデックスが必要です。

不具合の切り分けでは、まず本ごとのキャッシュ削除を優先してください。全体の読書キャッシュ消去は、読書位置を失ってもよい場合だけ実行してください。

## 不具合報告に必要な情報

次の5点があれば、設定に詳しくなくても調査を進められます。

1. 端末機種（X3 または X4）とファームウェアのバージョン
2. 問題が見える写真
3. 発生した場所（読書中、ホーム、スリープ画面など）
4. 直前の操作（設定変更、キャッシュ削除、画像ページ閲覧など）
5. ダークモードとスリープ画面の設定（分かる範囲で）

設定名や操作方法が分からない場合は、画面写真だけでも十分です。初期化や SD カードの削除は、案内があるまで行わないでください。
