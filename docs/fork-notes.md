- 現在のベースは上流 **`v0.6.3`**（本ごとの読書設定・読書設定テスト表示・設定バックアップ等）。`integrate/upstream-v0.6.3` 統合ブランチ・`v0.6.3-merge`。

### 上流 v0.6.2 + v0.6.3 で取り込まれた上流機能（2026-08-29 統合・実機確認前）

ベース更新時に上流から入ってきた機能。フォーク独自実装ではない（下の「フォーク独自実装」には含めない）。README・基本操作・ロードマップは**上流記載に統一**した（フォーク独自の状況メモ＝README冒頭の `> [!IMPORTANT]` ブロックと本ファイルのみ維持）。**この記録は統合時点のもので、実機確認は未実施**。

- **本ごとの読書設定（Book Override）**: EPUB読書中に `読書設定 → この本の設定` から、その本だけに縦横書き・フォント・文字サイズ・行間・余白・ルビ位置・書籍スタイルを保存できる。`全体設定を使用` でその本だけの設定を破棄して全体設定へ戻る。設定は書籍パスとソース指紋に結び付く。
- **読書設定テスト表示**: 縦書き／横書き、ルビ、長文改行、句読点・括弧、英数字・縦中横、長音、太字を固定サンプルで現在の設定のまま確認できる。`決定` でルビ位置調整へ。
- **ルビ位置（`rubyOffset`）を正式な読書設定として追加**: 全体設定と本ごとの設定で個別指定可能。設定バックアップ・復元にも対応。旧設定は `0` として読み込む。
- **ルビ列間隔の改善（Issue #27）**: 設定した行間を基本に、不足分だけ衝突回避の間隔を補う。ルビ位置調整と衝突回避量を分離。これに伴いキャッシュバージョンを上流の `SECTION_FILE_VERSION=92` へ更新（フォークの三点リーダー分割＝v90 の実コードは維持、コメントを追記）。
- **縦書きの字形改善**: 全角コロン／セミコロン（`：；`）をBIZUD基準の左右並びに統一、Noto系の半角長音（`ｰ`）左寄りを修正。
- **読書設定プロファイルの保存・読込改善**: 未導入SDフォントは安全な代替フォントで読み込み、壊れたプロファイルは適用しない。
- **設定バックアップ・復元、診断情報の拡充**: 診断レポート（本文・画像・Wi-Fi認証情報を含まない）をSDカードへ保存可能。キャッシュ使用量・書籍情報・ソース指紋を表示。
- **Noto Serif JP を Medium / Bold に更新**（通常を `wght:500`、太字を `wght:700`）。
- **EPUB内のSVG画像参照、未対応絵文字の代替表示、UI文字範囲の拡充**。
- **Serial初期化修正（上流側）**: 上流も同じ `delay(250)` + `Serial.begin` + `setTxTimeoutMs(1)` を入れたが、フォークは既に PR#69 移植で実装済みのため**フォーク版（日本語コメント付き）を維持**。機能的に同一。

### 上流 v0.6.1 で取り込まれた上流機能（2026-08-25・実機確認済み）

ベース更新時に上流から入ってきた機能。フォーク独自実装ではない（下の「フォーク独自実装」には含めない）。

- **`words`/`rubyTexts` を `std::vector` → `std::deque` に変更（OOMクラッシュ対策）**: 大きな `<ruby>` ベース文字列が vector の連続メモリ確保を要求し、X3の断片化ヒープで `bad_alloc` → abort する問題を修正。deque は小ブロックで成長するため最大確保サイズが有界になる。`reserve` も `wordStyles`/`wordContinues` の小さい並列メタデータのみに縮小。
- **章スキップの範囲チェック**: 章スキップ時に隣接章が存在しない場合、従来は範囲外スパインインデックスを代入して**1章だけの本が先頭/末尾に巻き戻る**バグを修正。`targetSpineIndex` が有効範囲内のときだけスキップするようガード。
- **Serial初期化修正**: 上流も同じ修正（`delay(250)` + `Serial.begin(115200)` + `logSerial.setTxTimeoutMs(1)`）を入れたが、**フォークは既に PR#69 移植で実装済みのため、フォーク版（日本語コメント付き）を維持**。機能的に同一。

## フォーク独自実装（上流 v0.6.0 との差分が残るもの）

### 表示・縦書き

- **縦書きの段落配置を両端揃え(Justify)に固定**:縦書きは列位置が右詰め固定で`paragraphAlignment`が描画に反映されず、インデント判定(`Justify||Left`)のみに使われる。そのため縦書き設定で「中央揃え」「右揃え」を選ぶと**行頭インデントが機能しない**不整合があった(Kindleは段落配置が両端揃えデフォルトのためインデントが付く)。縦書きの段落配置をJustifyに固定し、縦書き設定画面の「段落配置」項目を削除(横書きは従来どおり選択可能)。`SECTION_FILE_VERSION`を79にbump。実機確認済み(2026-08-17)。
- **行頭が全角空白で始まる段落の二重インデントを解消**: 行頭インデントを全角空白(U+3000)で表現している書籍(文庫系EPUBの一般的な形式)で、全角空白の表示(v0.3.8.2以降)と行頭インデント機能が重複して**2文字分**空いてしまう問題を修正。段落の先頭がU+3000で始まるときはリーダーの自動インデントを適用しない(Kindle相当・全角空白がインデントの役割を果たす)。縦書き(`verticalIndent`)・横書き(`textIndent`注入)の両方に適用。`SECTION_FILE_VERSION`を80にbump。実機確認済み(2026-08-17)。上流PR #21として投稿。
- **縦書き句読点描画の無意味な二重`loadVertData`呼び出しを解消**(2026-08-19): 上流v0.4.0で導入された`drawTextVertical()`内の`loadVertData()`二重呼び出し(初回失敗時にもう一度同じ引数で呼ぶ恒等no-op)を単一呼び出しに修正。挙動は不変のリファクタのみ。
- **ページ送り中インジケータ**: ページ送り操作を受け付けたときに、ステータスバーに**送り方向の矢印**(◀/▶)を一瞬表示。e-inkの描画待ち時間に「反応した」ことが伝わる。ステータスバーカスタマイズでオン/オフ可能(実機・web両対応)。drawLineで図形描画(フォント非依存で「?」化しない)。バッテリー残量表示の右側に配置し、しおり表示とも重ならない。**EPUB専用**(XTCはページ画像にステータスバー込みのため対象外)。
- **章一覧から「ファイル途中を指す目次項目」を除外**: 1つのXHTMLファイル内に複数の章・脚注が同居するEPUB(例:三体2下巻の第2〜5章がc246.xhtmlに同居)で、`c246.xhtml#a3H8`のように**アンカー付きでファイル途中を指す目次項目**が章一覧に並んでしまう問題を修正。`createTocEntry`で`anchor`が空でないTOC項目をスキップし、**ファイル全体を指す項目だけを章として表示**。Kindleアプリと同様の章一覧になる(大区分のみ表示)。`BOOK_CACHE_VERSION`を8にbump(既存book.bin再生成)。
- **三点リーダー(…)の極長連続で改行が破綻する問題を修正**(2026-08-25): 文庫系EPUBで「……」(U+2026)が**300個以上**連続する箇所(例:「〜にまで……(322個)…の瞬間」)で、`isCjkCodepointForSplit`にU+2026が含まれていないため、連続全体が**1つの改行不能な巨大ワード**としてバッファリングされ、改行計算が破綻して**画面端まで点が埋まる**問題を修正。U+2026「…」とU+2025「‥」を個別文字(ワード)として分割するよう`isCjkCodepointForSplit`に追加。縦書きでは既にupright登録済み・禁則対象として既知なので、分割後は行頭禁則が正しく働く。`SECTION_FILE_VERSION`を90にbump(既存セクションキャッシュ再生成)。実機確認済み(2026-08-25)。

### インライン画像

- **インライン画像のサンセリフ(ゴシック)表示対応**(2026-08-19): テキスト中に埋め込まれたインライン画像(外字・代替文字)が、サンセリフフォントで「単一の画像ページ(ブロック図版)」に化けてしまう問題を修正。インライン化判定(`fitsInline`)が縦書きで「文字『一』の実グリフ幅」を基準にしていたため、グリフ幅が狭いサンセリフではCSS `1em`の画像が判定から漏れて専用ページ化していた。縦書きの判定基準を「文字セル1つ分=フォントサイズ(`emSize`)」に変更し、フォントファミリに依存しない判定にした。`SECTION_FILE_VERSION`を83にbump(キャッシュ再生成)。併せて、縦書きのインライン画像を「次の文字までの高さ」をセルとして縦中心に配置するようにした(横書きの行内中央配置と対称)。ただし段落末・列末など画像で行が終わって次の文字がない場合(末尾要素)は、列の残り高さ全体をセル下端に使うと画像が画面中央まで下がるため、元の位置を維持するようにした(2026-08-19 上流PR#22レビュー対応。X3実機確認済み)。※ インライン画像の**表示サイズ・縦位置の微調整**は、明朝とサンセリフでフォントメトリクス(ascender等)が異なるため後回し(既知の問題として記録)。

- **SDフォントのkern行キャッシュ**(2026-08-20): 大きなSDフォントのkern表を連続確保できない場合、必要な行だけをSDカードから読む方式に切り替える。メモリ断片化時の確保失敗を抑え、読書・ホーム画面を安定化。`SdCardFont.cpp/h` の `kernRowCache`（行キャッシュ）は**フォーク独自実装**（上流v0.4.1には無い。上流v0.4.1のkern基本部分を移植したうえで追加した改善）。実機確認済み(2026-08-20)。

### 安定性・ビルド

- **バッテリー満充電時にUSB Serialが有効化されない問題の修正**(2026-08-20): 上流 zrn-ns crosspoint-jp PR#69 を移植。`main.cpp` の `ENABLE_SERIAL_LOG` ブロックで `Serial.begin()` を `gpio.isUsbConnected()` でゲートしていたが、X3 では `HalGPIO::isUsbConnected()` が BQ27220 の充電電流(充電中=電流>0)で USB 接続を推測するため、バッテリー100%で充電電流0mAになると USB 接続時でも `Serial.begin()` が呼ばれず、フラッシュ・シリアル監視が不能になる副次作用があった(crosspoint-reader/#2467)。対策として `Serial.begin()` を無条件化し、先頭に250ms delay(USB Serial/JTAG ペリフェラルの電源投入+ホスト側enumeration完了待ち、cold boot race対策)、さらに `logSerial.setTxTimeoutMs(1)`(CDC未接続時のwriteブロック防止)を追加。上流 crosspoint-reader/develop の方針と同一。commit `bc3a341`。
- **drawArc/fillArc の走査ベース高速化**(2026-08-20): 上流 crosspoint-reader #1540 を移植。円弧描画を全領域走査(dx×dyの二重ループ)から「行ごとに x 境界を走査して `fillRect` で水平ラインを塗る」方式に変更し、余分なピクセル判定を削減。フォークの GfxRenderer には既に `fillRect` / `fillRectDither` / `Color::Clear` / `getScreenHeight()` が揃っていたため追加ヘッダ変更なし。X3 実機確認済み(2026-08-20)。
- **フォーク専用 clang-format ツールチェーン＋CI**: `bin/fork-clang-format-fix`(変更行のみ整形)と `fork-clang-format.yml` を追加。上流コードを汚さずフォーク変更行だけ整形・CIチェックする。

## 意図的に取り込んでいない上流機能

- **縦書きでの矢印(←↑→↓)の直立表示**(上流v0.3.8.2): 上流は縦書きで矢印を「直立(回転なし)」表示する変更を入れたが、**Kindle版と表示の向きが一致しない**ため、フォークでは意図的に取り込まない。Kindle版では矢印は回転(Sideways)表示されており、フォークは従来どおり回転表示を維持してKindle版と挙動を一致させる。※ この判断は実機でのKindle版との比較確認に基づく(2026-08-16)。

## 未解決(既知の問題)

- **XTCHの「メモリエラー」**: キャッシュ生成プロセスがヒープを断片化させることが原因と判明。再現手順:XTCHを開く→他EPUBのキャッシュ生成→最初のXTCHを再度開く。診断:空きヒープ152KBなのに最大連続ブロック54KB(断片化)。幅0回避とは無関係。EPUB読書には影響しないため一旦保留。
- **インライン画像の表示位置が明朝体以外で少しずれる**(2026-08-19): テキスト中に埋め込まれたインライン画像(外字・代替文字)の縦方向の表示位置が、**明朝体では自然だが、サンセリフ(ゴシック)等の他のフォントでは少しズレる**場合がある。原因は、フォント(明朝/サンセリフ)で `ascender` 等のメトリクスが異なるため、両方に完全一致する1つの配置式が見つけられていないこと。サンセリフでの「単一画像ページ化(ブロック図版化)」は解消済みだが、位置の微調整(画像が少し上に浮く/下の隙間が広い等)は対応検討中。
