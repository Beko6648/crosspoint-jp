# キャッシュ中断操作・Home表紙未準備の修正

基点 main 8bb1d1ab。X3/X4実機確認済み。Home表紙と中断操作を別コミットで記録。

## Home表紙
loadRecentCoversはepub.load(false,true)の戻り値を無視し、キャッシュ削除後の未読込状態でもgenerateThumbBmpを呼んでいた。falseなら生成を見送り、既存の表紙パスを保持する。次回Home表示で再試行する。generateThumbBmp本体の本当のエラー記録は維持。

## 中断
単体・一括の共通CacheGenerationControlsを、マッピング済みBackの約1000ms長押しに変更。最初にBack解放を観測してから判定を開始。短押しと他ボタンでは中断しない。受付後はラッチし、次の処理区切りで停止。通常の画面操作はBack解放フレームも消費して再開する。一括生成開始を呼んだ同じloop内でBack判定へ流れないようreturnする。
POWER+DOWNのスクリーンショットを優先し、長押し計測をリセットする。
入力は同期処理の確認箇所で観測するため、1秒で必ず停止する保証ではない。確認間隔中の短い押し離しを完全追跡する仕組みではない。画像デコード内の新しい入力タスクは追加しない。
単体生成の停止時は既存の中断文言を進捗ポップアップへ表示。一括生成は既存の中断結果画面を使用。危険な処理途中で画面更新する中断受付オーバーレイは追加しない。

## 検証
ホストテスト: 開始時押下、短押し、1000ms境界、中断保持、解放消費、スクリーンショット優先、millis周回で成功。
