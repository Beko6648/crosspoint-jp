# 読書データを共有する

[マニュアルの目次](manual-ja.md)

この機能は **v0.8.1以降** のX3 / X4で利用できます。公開済みのv0.8.0には含まれません。

## 共有できるもの

同じEPUBについて、読書位置・しおり・本ごとの表示設定・本別の読書履歴を、1冊ずつJSONファイルで受け渡します。共有する種類は個別に選べます。EPUB本体、フォント、端末全体の設定、Wi-Fi情報は含みません。

両端末に同じEPUBを用意してください。同じタイトルでも、更新版や再圧縮したファイルではBookIDが異なることがあります。BookIDが違う本には取り込めません。改名だけで内容が同じEPUBは同じ対象として扱います。

共有ファイルは1～65,536バイトです。TXT・XTC/XTCH、複数冊の一括共有、自動同期、端末同士の直接通信は対象外です。

## SDカードで受け渡す

1. 送信側で対象のEPUBを開き、**決定 → ツール → SDで読書データを共有** を選びます。
2. **この本のデータを書き出す** を選び、共有する種類を選択します。
3. **変更内容を確認する** へ進み、確認画面を読み、最終ページで **確認して書き出す** を実行します。
4. 保存された `/YomukaSync/<BookID>.json` をPCなどへコピーします。同じ本の書き出し先は同じファイル名です。以前の版を残す場合は別途コピーしてください。
5. 受信側のSDカードの `/YomukaSync/` にJSONをコピーします。受信側でも対象のEPUBを開き、同じ共有メニューから **この本のデータを取り込む** を選びます。
6. ファイルと取り込む種類を選び、差分を確認して最終ページで **確認して取り込む** を実行します。

取り込み一覧には、開いている本とBookIDが一致する、有効な共有ファイルだけが表示されます。ファイル名を変えても別の本に適用できるようにはなりません。同じ本のファイルが複数あれば、ファイル名で選びます。一覧はフォルダ内の最大64件を走査するため、必要なファイルが見つからない場合はPCで共有フォルダを整理してください。

SDカードは端末の電源を切り、書き込みが終わってから取り外してください。

## Webから受け渡す

1. [Wi-Fiとファイル転送](wifi-transfer-ja.md)の手順で、端末のWeb画面を開きます。
2. ファイル管理で対象のEPUBの **共有** を選び、本のタイトルを確認します。初めて使う本で情報を読み込めない場合は、いったん端末でその本を開いてからWeb画面へ戻ります。
3. 書き出す場合は種類を選び、**選んだデータを書き出す** でJSONをPC・スマートフォンに保存します。
4. 受け取る場合は同じ本のJSONを選び、**共有ファイルを端末へ送る** を実行し、受信結果を確認します。同じ本の受信済み共有ファイルは置き換わります。
5. 受信成功後、端末のWi-Fi転送画面を終了します。本を開き、**SDで読書データを共有 → この本のデータを取り込む** から内容を確認して適用します。

**Webへの送信成功だけでは読書データは変わりません。** 適用には端末の確認操作が必要です。通信が途切れた場合は再接続し、受信結果を確認してから再送してください。JSONを本体ファイルのアップロード画面へ送る操作とは区別してください。

## 確認画面と置き換わる内容

比較ページは **前頁 / 次頁** で移動します。比較ページの決定ボタンでは保存せず、最終ページの実行で適用します。戻ると種類を選び直せます。画面は縦向きです。

選んでいない種類と、他の本のデータは変更しません。選んだ種類は受信内容で全体を置き換えます。

| 種類 | 確認すること |
|---|---|
| 読書位置 | 受信側のフォント・余白・書字方向で再計算するため、位置は近似です。章・ページ番号の完全一致は保証しません |
| しおり | 既存の一覧を置き換えます。受信一覧が空の場合は全削除です |
| 本の設定 | 保存済みの本固有設定を置き換えます。受信にない項目は上書きを解除し、端末の全体設定を継承します。必要なSDフォントがなければ、この種類を取り込めません |
| 本別の読書履歴 | 本別の要約を置き換え、加算しません。端末全体・日別の累計は保持します。取り込み後に本を開いて読む操作は新しい読書セッションとして記録されます |

本の設定を取り込むと、完了画面からHomeへ戻ります。同じ本を開き直して反映を確認してください。設定を含まない場合は、完了画面から取り込んだデータで本を開き直します。

## 日時と失敗時の扱い

時計が分からないときの更新日時は「不明」です。X4でも、共有ファイルに記録された更新日時は保持します。その後、端末側でデータを変更した時点の時計が不明なら、その種類の更新日時は不明になります。PCで書き出した時刻やSDファイルの更新時刻で代用しません。

受信データの更新日時が古い場合は注意が表示されますが、自動で新しい方を選ぶ機能ではありません。日時不明の場合は新旧を判断せず、内容を確認してください。

不正・別の本・過大なJSONは拒否されます。取り込み失敗時は画面の案内を確認してください。「復旧が必要」「再起動してください」と表示された場合は、SDカードの状態を確認し、再起動します。復旧用ファイルや `/.crosspoint/` 全体を自己判断で削除しないでください。

X3 / X4の相互共有、Web送受信、通常再起動後の保持、通信中断後の再使用は確認済みです。保存途中のSD失敗・電源断・復旧中の再失敗はホスト検証のみで、実機では未確認です。
