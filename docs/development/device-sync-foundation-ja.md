# 端末間読書データ共有の基礎

X3、X4、将来のX4 V2／Proで読書データを交換するための基盤。外部クラウドや自動同期から始めず、利用者が対象と差分を確認できる手動同期を先に実装します。

## v0.8.0で確定する形式

[同期スナップショットv1仕様](sync-snapshot-v1-ja.md)を正本とします。読書位置、しおり、本ごとの表示設定、読書履歴の4種類を1冊単位のJSONで交換し、種類ごとに選択して全体置換します。以前ここに載せた最小JSONは未実装の草案であり、v1仕様に置き換えました。

更新日時が有効でも自動適用はしません。現行の4種類には更新日時がないため、既存データからの初回書き出しはupdatedAt=0です。履歴の最終読書日時や書き出し日時を流用しません。

## 現在の保存基盤

EPUBはZIPの中央ディレクトリ等から計算する64-bitのBookIdで識別します。改名・移動では変化しませんが、再圧縮やZIPメタデータ変更で変わり得ます。本文の意味的な同一性を保証する指紋ではありません。

- 読書位置としおり：`/.crosspoint/books/<BookId>/progress.bin`と`bookmarks.json`
- 本ごとの表示設定：`/.crosspoint/book-reader-settings.json`のBookId別項目
- 読書履歴：`/.crosspoint/reading-history.json`のBookId付き本別記録

EPUB本体、キャッシュ、全体設定、Wi-Fi情報は交換しません。履歴の端末全体・日別集計も本別に分解できないため対象外です。詳細な変換、空データ、競合、互換性はv1仕様に従います。

## 導入順

1. **v0.7.4（完了）**：内容指紋を使う保存基盤を導入した。同期用UIや通信は追加しない。
2. **v0.7.7**：診断、安定性、Landscape UIを優先する。読書データ共有の機能追加は行わない。
3. **v0.7.8**：読書レスポンスやキャッシュ性能を改善する。同期データの入出力はまだ追加しない。
4. **v0.8.0**：X4 V2／Proを含む端末共通基盤を整理し、`BookId`、同期スナップショットの形式、各データの更新日時と互換性規則を確定する。X3/X4で同じ本を同じ`BookId`として扱えることを確認する。
5. **v0.8.1**：SDカードまたはWebUIで読み書きできる手動同期スナップショットを追加する。取り込み前に対象の本と差分を表示し、読書位置、しおり、本ごとの表示設定、読書履歴を個別に選べるようにする。異なる書字方向・フォントでの位置復元をX3/X4で確認する。
6. **v0.8.2以降**：競合処理を改善し、Yomuka端末同士で同期スナップショットを直接送受信する。同じWi-Fiへ接続する方式を先に検討し、ルーターがない場所では片方の端末をアクセスポイントにする方式を候補にする。

この順序なら、X4 V2／Proの追加によって同期データ形式を分岐させずに済みます。また、位置同期の導入だけで、しおりや本ごとの設定、履歴が意図せず上書きされることを防げます。

## v0.8.1の最初の範囲

- 端末Aで同期スナップショットを書き出す
- SDカードまたはWebUIで端末Bへ渡す
- 端末Bに同じ`BookId`の本がある場合だけ取り込み候補にする
- 自動適用せず、対象の本、更新日時、取り込むデータ種別を画面で確認する
- 時刻を比較できない場合は、端末側のデータと受け取ったデータのどちらを使うか選択する
- EPUB本体、表示キャッシュ、Wi-Fi設定、端末全体の設定は含めない

## 端末同士のWi-Fi共有

Yomukaには、通常のWi-Fi接続と端末のアクセスポイントモードで動作するWebサーバー、およびHTTPクライアントの基盤があります。このため、一方の端末が同期データを公開し、もう一方の端末がHTTPで取得する構成が可能です。

最初は、両方の端末を同じWi-Fiへ接続する方式を優先します。送信側で「読書データを共有」を開いている間だけ同期用URLと一時コードを表示し、受信側で送信元IPまたは端末名とコードを入力して接続します。取り込み内容は転送後に受信側で確認し、自動適用しません。

ルーターを使えない場合は、送信側を一時的なアクセスポイントにして受信側を接続する方式も実装できます。ただし、保存済みWi-Fiからの切り替え、接続復元、画面スリープ、同時にWebサーバーとHTTPクライアントを扱う際のメモリを実機で確認する必要があります。

端末の自動探索は最初の必須要件にしません。IPアドレスまたは端末名による接続を先に実装し、mDNSなどの探索は安定性を確認してから追加します。同期用URLは共有画面を閉じたら無効にし、受信側で対象の本とデータ種別を確認してから適用します。
