# v0.7.7 診断・安定性 作業記録

v0.7.7は、X3の個体差を利用者自身が確認できる診断機能と、実測に基づく傾きページ送り調整を優先する。Landscape UIは診断・安定性項目の実機確認後に着手する。

## X3 傾きセンサー診断

- 設定の「システム」に「傾きセンサー診断」を追加する。QMI8658を検出したX3だけに表示し、X4とX4 Classicには表示しない。
- 右・左を一度ずつ試し、センサーの方向反応（50 deg/s以上）、右・左ピーク、ページ送り基準（270 deg/s）への到達、静止域の揺れ、I2Cエラー数を表示する。
- 生の加速度と角速度、判定軸、現在値、trigger/neutral閾値、I2Cアドレス、Awake/Sleepを詳細画面に表示する。
- 診断結果は `/.crosspoint/diagnostics/imu_report_*.txt` に保存できる。自動で閾値は変更せず、センサーの反応と上流版の基準へ到達したかを案内する。
- ページ送り判定はCrossPoint 1.6.5rcと同じ角速度方式（trigger 270 deg/s、neutral 50 deg/s、cooldown 600 ms、20 Hz）を使う。実験した角度積算と感度別閾値は採用しない。

## FreeInk IMU差分

FreeInk SDKは `fde240f` からPR #99 mergeの `bc31e96` へ更新する。Yomuka独自のQMI8658レジスタ制御をSDK `Imu`へ置き換え、次をSDK側へ統一する。

- QMI8658を28 Hzから約117 Hzへ変更
- `BIG_ENDIAN`指定を外し、SDKのlittle-endian読み取りと一致させる
- 0x6A / 0x6B fallback
- accel + gyroの同一sample取得
- センサーエンジンと発振器を含むsleep/wake

PR #99後の `97947f1` は基板ごとのIMU軸補正を追加するが、X3 profileには補正値を追加しない。今回は無関係なSDK差分を広げないため採用せず、Yomukaの4方向マッピングを診断画面で実機確認する。

## 実機確認待ち

1. Portrait / Inverted / Landscape CW / Landscape CCWで右・左の表示とページ方向が一致すること。
2. 右・左を各3回行い、peakとcrossingが取りこぼされないこと。
3. 左右とも270 deg/sに届いた場合と、センサーは反応するが270 deg/s未満の場合を区別できること。
4. 診断終了後とスリープ時にQMI8658がpower-downし、読書へ戻ると復帰すること。
5. 保存レポートにversion、device、IMU、address、FreeInk revision、生値、peak、idle noise、上流判定基準、I2C errorが含まれること。
