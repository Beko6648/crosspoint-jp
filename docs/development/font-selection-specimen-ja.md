# フォント選択の字体見本（試作）

フォント一覧を移動すると、その候補の見本を表示する。決定するまで読書設定は変更せず、戻ると従来の設定を維持する。変更対象は呼び出し元の縦書き用／横書き用フォントで、見本自体は常に横書き14pt（中相当）。

縦向きは上に見本・下に一覧、横向きは左に見本・右に一覧。現在の回転方向に対応したボタン案内の位置は維持する。長いフォント名は省略表示。画面や字体によって見本文が収まらない場合は一部表示と注記する。

英数字と日本語の固定見本を使う。未収録または読み込めない文字は空白とし、見本の下に注記する。日本語部分をUIフォントで代替しない。ファイルを読めない場合は「見本を読み込めません」と表示する。

14ptファイルがない場合は、最も近いサイズ（同距離なら大きい方）のRegularを14ptへ換算して表示。枠に収めるための自動縮小は行わない。見本は字形比較用に1文字ずつ描き、本文のカーニング・縦書き・ルビ等を再現する画面ではない。それらは既存の読書プレビューで確認する。

候補は一時的なSdCardFontとして描画ロック中だけ登録し、描画後に登録・倍率・フォントを解放する。本文用フォントを差し替えず、設定や読書キャッシュを保存しない。候補の読み込み時間・低メモリ時の動作は実機確認が必要。

## 実機確認手順

1. X3またはX4で縦向きのフォント一覧を開き、上の字体見本と下の選択行を確認。
2. 日本語フォントを2〜3種類切り替え、字体が変わること、候補切替の待ち時間を確認。
3. 英文フォントがあれば選び、日本語が空白になり注記が出ることを確認。
4. 戻って本を開き、フォント・文字サイズが変わっていないことを確認。
5. 再度選んで決定し、呼び出し元の縦書き／横書き用フォントにだけ適用されることを確認。
6. 右回転・左回転の画面で左見本／右一覧、長い名前、選択済み表示、ボタン案内との重なりを確認。
7. 縦書き用と横書き用の両方から開く。本ごとの設定からも選び、既存の設定範囲を維持することを確認。
8. 連続切替後、既存の読書プレビュー、縦書きの句読点、画像→本文、sleep/wakeを確認。

文字AAは追加しない。rc1の元のbinは保存し、この試作binとは区別する。確認結果は以下に記録し、個別項目の全合格とは区別する。
