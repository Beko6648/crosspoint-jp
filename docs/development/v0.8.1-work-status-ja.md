# v0.8.1 作業一覧

更新日: 2026-10-02。基準: v0.8.0リリース済み。

本書はv0.8.1開発ブランチの実装状況を記す。
v0.8.1の主題は、読書位置・しおり・本固有設定・読書履歴を安全に受け渡す手動同期。

| 順番 | 作業 | 状況 |
|---|---|---|
| 1a | 読書位置の純粋変換、更新日時ポリシー、初期API監査 | 適用・ホストテスト済み。保存基盤から旧形式変換を使用 |
| 1b | 4種類の完全読み取り、保存成功通知、日時の永続化 | 保存基盤へ実装。3環境ビルド成功。X3/X4で通常保存・復元の1〜5を利用者確認済み（日時内容は未確認） |
| 2 | JSON全体の厳密検証とバックアップ/再起動復旧 | 端末側の全体検証・複数保存先の復旧基盤を実装。SD操作・変換・選択UIへ3で接続。X3/X4起動を利用者確認済み |
| 3 | 1冊単位のSD書き出し/取り込み | 読書メニューから接続。ホスト検証・3環境ビルド成功。利用者がX3→X4、X4→X3の共有成功を確認（2026-10-01） |
| 4 | 差分プレビュー、種類ごとの選択、削除/解除表示、履歴区分 | 全設定項目の詳細差分、しおり置換対象、履歴5項目、日時注意、選び直し・折返し・ページ表示を実装。ページ単位操作、図形アイコン、注意枠、設定取り込み後Home移動を追加。取り込み一覧を開いている本のBookIdで絞り込み。配置はX4で確認済み、共有ファイルの絞り込みは利用者確認済み。利用者の確認完了を受けてここまでをコミット（個別機種・項目の詳細記録は未追加） |

## 守る範囲

- 同一BookIdのEPUB、1ファイル1冊。種類を選んで全体置換し、無確認のマージをしない。
- BookIdの不一致をタイトルやファイル名で代用しない。
- 既存形式の互換性を維持し、実機で保存と復元を確認してから統合する。
- SDK更新、BLE、HAL全面再編、OTA/リカバリー刷新、TXT統合を混ぜない。
- X4CはExperimentalのまま。実機なしで対応済みに変更しない。
- 廃止済みの文字AAは復活させない。
