## 2026-10-03: 共有の追加実機確認

- 同じBookId `de8eae7657a039a6` のSD共有JSONを比較。X3からX4へ取り込み・再書き出し後、本の設定・読書位置・しおりの更新日時を保持。履歴は本を開いた操作で13秒・1セッション増え、時計不明のX4では更新日時が0になった。
- X4で読書位置を変更すると、位置の更新日時は0へ変化し、未変更のしおり・設定の日時は保持。X3への取り込みで読書位置の反映を利用者確認済み。
- X4で本固有の縦書きフォントを `noto-sans` / `NotoSansJp` に変更すると、設定の更新日時は0へ変化。X3への設定取り込みと表示反映を利用者確認済み。
- Web経由のX3書き出しとX4取り込み後の再書き出しでは、4種類すべての更新日時、設定、履歴の内容が一致。ページ数・一部のしおり位置は受信側レイアウトで再計算。X4の書き出し日時は0で、受信した更新日時を置き換えていない。
- X4で別BookId・壊れたJSON・65,537バイトJSONのブラウザ拒否、重複キーJSONの端末拒否、その後の正常JSON受信の1〜5を利用者確認済み。端末で試験用JSONの取り込みを行う手順ではない。
- 既存受信JSONを保持した通信中断試験はX3/X4で前後のバイト一致と正常再送を確認済み。X3/X4ともWi-Fi終了後の読書位置・しおり・本の設定保持を利用者確認済み。保存途中のSD失敗・電源断・復旧中の再失敗は引き続き実機未確認。

### 通常操作の最終回帰（2026-10-03）

現在の開発版で、利用者がX3・X4双方の次の1〜5をすべてOKと報告。

1. 普段の本を読み、読書位置・しおり・本の設定を確認。
2. WebでJSONを書き出し、そのJSONを端末へ送信。
3. Wi-Fiを終了し、端末で取り込みを実行。
4. 本を開き直し、位置・しおり・設定の反映を確認。
5. スリープ・復帰後も正常に読めることを確認。

これは現在の開発版の通常操作の確認であり、保存途中のSD障害・電源断・復旧再失敗の実機確認ではない。版番号・公開構成を変更した成果物の確認も別途必要。

## Issue #40の読み取り専用診断（2026-10-02、最初の診断版の記録）

この節は容量補正を追加する前の記録。最終的な容量補正・実機確認は後続の節を参照。

報告されたv0.7.8の83%→3%急落ログはfull_mAh=2872、remaining_mAh=86、voltage_mV=3544、current_mA=-50、valid=0xF。設計容量はまだ不明のため、ゲージ設定/学習値不一致の候補を確認する読み取り専用診断を追加した。容量補正・学習値書換え・Controlコマンド・リセットは行わない。

手動レポートにbattery_gauge_design_mAh、full_mAh、remaining_mAh、soc_percent、voltage_mV、current_mA、battery_status、operation_status、validマスクと取得時刻/所要時間を追加。OperationStatusからsecurity、cfgupdate、initcomp、edv2を出力。取得失敗はunknownとする。UI描画との競合を避けるためRenderLock内で順次読取り、原子的な同時スナップショットとはしていない。X4 ADC/S3では利用不可としてX3のレジスタを読まない。

急落/debugログに同じpoll_msのGAUGE_STATE行を追加。従来SOC_JUMPのvalidマスクは維持し、GAUGE_STATE側はdesign/BatteryStatus/OperationStatusの3ビットマスクを別に使用。ログの256バイト上限で情報が切れないように別行とした。ホスト3構成で読み取り・各レジスタ失敗/短縮読込み・SOCキャッシュ維持・ADC分離を検証済み。この最初の診断版作成時点では実機の診断レポート内容は確認待ちだった。後続の容量補正・診断表示改善と合わせてc6a922fdでコミット済み。

参照: [TI BQ27220 TRM](https://www.ti.com/lit/ug/sluubd4a/sluubd4a.pdf) 2.7/2.21/2.27/2.28。[上流SDK PR #132](https://github.com/Free-Ink/freeink-sdk/pull/132)と[本家PR #3730](https://github.com/crosspoint-reader/crosspoint-reader/pull/3730)は容量補正候補で、今回の差分には適用していない。

最初の診断版ビルド: default/gh_release成功（RAM49172、Flash4590001バイト）、x4c成功（RAM58880、Flash4481331バイト）。変更C++のclang-formatとgit diff --check成功。開発版の版表示はv0.8.0のまま。この時点ではX3/X4実機確認、コミット、GitHubへの投稿は未実施だった。後続の実機結果は以下に記録する。
