## CrossPoint Yomuka v0.8.0

> CrossPoint Yomuka は CrossPoint Reader / CrossPoint JP を基にした非公式コミュニティフォークです。

### 主な変更

- **フォント選択に字体見本を追加しました。** 英文・数字・日本語の横書き見本を表示します。縦向き画面では一覧の上、横向き画面では一覧の左に配置します。見本は14pt基準で、実際の読書設定とは別です。選んだフォントにない文字は空白にし、別フォントによる代替表示はしません。本文の組版やルビ位置は、従来の「読書設定テスト表示」で確認できます。
- **X4の横向き設定画面を調整しました。** 設定一覧に使える領域を広げました。Lyra系テーマの右側上では見出し・タブを上へ詰め、左側上でも下側の余白を減らしています。「読書設定テスト表示」も右側上で見出しと本文を上へ移し、本文領域を広げました。
- **保存したしおりの一覧を見分けやすくしました。** 各しおりの左に32pxのしおりアイコンを表示し、選択中は白く反転します。「この本のしおりすべてを削除する」は本文と行頭を揃え、アイコンを付けずに区別します。
- 描画処理とメインループの競合を減らし、ホットスポット通信中に本体の終了操作を確認する処理を改善しました。通信処理そのものを即座に中断する仕組みではありません。
- メモリが断片化した状態で、縦書き用の字形を読み込める条件を改善しました。ホットスポット利用後の句読点などの表示異常に対する対策です。最初に報告された異常との因果関係は未確定で、すべての再発を防ぐ保証ではありません。
- 自動ページ送りの日本語表記を、送り間隔が秒単位で分かる表記に変更しました。動作や保存値は変更していません。
- FreeInk SDKを段階更新し、X4 Classicの画面コントローラー検出・診断基盤を改善しました。スリープ開始失敗情報をSDKから取得できた場合の診断も追加しています。X3の傾き判定とYomuka独自のSD更新・復旧処理は維持しています。
- 将来の手動同期に向け、読書位置・しおり・本ごとの表示設定・読書履歴の4種類のデータ形式を定義しました。**端末間の書き出し・取り込み機能は、この版には含まれません。**

### 対応機種と確認範囲

| 機種 | 確認状況 |
|---|---|
| X3 | SDK更新後の読書・画像・スリープ等とフォント見本を実機確認 |
| X4 | SDK更新後の読書・画像・電源操作等を実機確認。今回の横向き設定画面・読書テスト画面は実機確認済み |
| X4 Classic | Experimental。ビルド・host検証のみで、実機表示や電源動作は未確認 |

X4V2／Pro全般の動作保証は含みません。

### 更新時の注意・既知の制限

- 今回のフォント見本・設定画面・しおり一覧の変更のために、読書キャッシュを削除する必要はありません。しおりの保存形式と削除操作は変更していません。
- X3の傾きページ送りの反応しづらさは、v0.7.8でも報告されている継続課題です。
- 初回のWebフリーズ、Wi-Fi終了時の診断ログ、X3バッテリーに関するIssue #40は継続調査中です。
- スリープ開始失敗の診断追加は、SDK側の異常復旧効果を保証するものではありません。
- 通常のX4にはRTCがありません。RTCに関する確認はX3の該当構成が対象です。

### 参考にした上流・開発基盤

FreeInk SDKは `bc31e96` から `18e73e16a1965fb19c62fa3a717cbc3a5b43add3` へ固定更新しました。CrossPoint本家 #3652の描画競合改善の考え方を、Yomukaの構成に合わせて選択適用しています。SDK mainへの一括更新、FreeType／FreeInkUI移行、RecoveryBootへの置換は行っていません。機種別ビルドとhost回帰検証の基盤も整備しました。

### 更新方法

1. 公開されたv0.8.0の `firmware.bin` をSDカードへ置きます。
2. **設定 → 管理 → SDカードファームウェア更新**を実行します。
3. 更新中は電源を切ったりSDカードを抜いたりしないでください。

X3／通常X4用とX4 Classic用のファームウェアは異なります。X4 Classic用はExperimentalです。通常のSD更新には `firmware.bin` を使い、`bootloader.bin` と `partitions.bin` は初回書き込み・復旧用です。
