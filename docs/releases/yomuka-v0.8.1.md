## CrossPoint Yomuka v0.8.1

> CrossPoint Yomuka は CrossPoint Reader / CrossPoint JP を基にした非公式コミュニティフォークです。

### 読書データを1冊ずつ共有

同じEPUBの **読書位置・しおり・本ごとの表示設定・本別の読書履歴** を、JSONファイルで別端末へ渡せます。SDカードへの書き出し・取り込みと、WebUIからのダウンロード・送信に対応しました。

- 共有する種類を個別に選び、端末の確認画面で変更内容を見てから取り込みます。選んだ種類は受信内容で置き換え、他の種類と他の本は保持します。
- 取り込み一覧には、開いている本とBookIDが一致する有効な共有ファイルを表示します。同じタイトルでもBookIDが違う本には取り込めません。
- Webで受信しただけでは読書データを変更しません。Wi-Fiを終了し、その本の **ツール → SDで読書データを共有** から取り込んでください。
- 本の設定を取り込むと完了画面からHomeへ戻ります。本を開き直して反映を確認してください。
- 時計が不明でも共有できます。受信した更新日時を保持し、その後に時計不明の端末で変更した種類は日時を「不明」にします。日時だけで自動的に上書きを決めません。

操作と置き換わる範囲は[読書データ共有マニュアル](https://github.com/ponto1216-ai/crosspoint-jp/blob/yomuka-v0.8.1/docs/reading-data-sharing-ja.md)を参照してください。

### Yomuka独自の診断改善

- **診断画面をすぐ開けるようにしました。** SD容量・キャッシュ量の集計を後回しにし、「再取得」で保存せず確認できます。再取得とレポート保存では「確認中…」を表示します。レポート保存時も改めて集計するため、事前の再取得は不要です。

### 上流からの取り込み

以下はCrossPoint 1.6.5およびFreeInk SDKの修正を、Yomukaの構成に合わせて取り込んだ変更です。

- **CrossPoint 1.6.5：長いタイトルの省略処理。** 省略表示するときの処理を軽くしました。
- **CrossPoint 1.6.5：Progressive JPEGの表示修正。** 白黒・グレー表示の乱れを修正しました。
- **CrossPoint 1.6.5：SDフォントの空白・合字処理。** 空白幅の扱いと、合字データ解放後の参照を修正しました。
- **CrossPoint 1.6.5：短いボタン押下の対策。** 待機後の短い押下を拾いやすくしました。ボタン割り当て・長押し・傾き感知の基準は従来どおりです。
- **CrossPoint 1.6.5：読めない本の復帰対策。** 本文を表示できた本を復帰対象として記録し、読めない本を復帰時に繰り返し開くことを防ぎます。Yomuka側の追加対応として、空のTXTを「空のファイル」と表示します。
- **FreeInk SDK PR #132：X3のバッテリー容量補正。** 不適切な容量設定を検出した場合に650mAhへ補正する対策を取り込みました。手元のX3では補正後の設定・保護復帰と通常操作を確認しています。残量急落が長期使用で解消するか、Issue #40の報告者端末でも改善するかは引き続き確認中です。

FreeInk SDKの固定リビジョンは `18e73e16` のまま、上記の容量補正処理を限定的に移植しています。

### 確認範囲と制限

- X3 / X4で相互共有、SD・Web経由の更新日時、異常JSONの拒否、通信中断時の既存共有JSON保持と正常再送、通常再起動、読書・取り込み後のスリープ復帰を確認しました。
- **保存途中のSD障害・電源断・復旧中の再失敗はホスト検証済みですが、実機では未確認です。** 通信中断や通常再起動の確認とは別の範囲です。共有前に必要なSDデータをバックアップしてください。
- 共有は同じBookIDのEPUB、1ファイル1冊、最大65,536バイトです。EPUB本体・フォント・端末全体設定・Wi-Fi情報は含みません。複数冊の一括共有・自動同期・端末同士の直接通信には対応しません。
- 読書位置は受信側の組版に合わせて再計算するため近似です。しおりと本の設定は選択した種類の全体置換です。本別履歴は加算せず置き換え、端末全体・日別の累計は保持します。
- 読書データ共有の端末画面は縦向きです。X3の傾きページ送りの反応しづらさ、初回Webフリーズ・Wi-Fi終了時の診断ログなどは継続調査とします。
- X4 Classic（X4 V2）はExperimental基盤のビルドのみで、実機未確認です。通常X4用の安定版を使用しないでください。X4V2／Pro全般の動作保証は含みません。

### 更新時の注意

章キャッシュ形式を更新したため、旧キャッシュは必要に応じて再生成します。更新後に本を開くと初回表示に時間がかかる場合があります。フォントファイルの一括入れ替えや、SDのキャッシュ全削除は不要です。

1. 公開されたv0.8.1の `firmware.bin` をSDカードへ置きます。
2. **設定 → 管理 → SDカードファームウェア更新**を実行します。
3. 更新中は電源を切ったりSDカードを抜いたりしないでください。

通常のSD更新には `firmware.bin` を使います。`bootloader.bin` と `partitions.bin` は初回書き込み・復旧用です。
