## CrossPoint Yomuka v0.6.3

> CrossPoint Yomuka は CrossPoint Reader / CrossPoint JP を基にした非公式コミュニティフォークです。

### 新機能

- EPUBごとに読書設定を保存できるようになりました。読書中に **決定 → 読書設定 → この本の設定** を開き、フォント、文字サイズ、行間・文字間隔、余白、ルビ、縦横書き、書籍スタイルをこの本だけに設定できます。
- `現在の設定を保存` で現在の読書設定を一括保存し、`全体設定を使用` で本ごとの設定を消して全体設定へ戻せます。
- **設定 → 読書 → 読書設定テスト表示** を追加しました。縦書き／横書き、ルビ、長文の改行、句読点・括弧、英数字・縦中横、長音、太字を、現在の設定で確認できます。
- ルビ位置を読書設定として保存できるようにしました。テスト表示または **決定 → 表示とレイアウト → ルビ位置調整** からX/Y方向を調整できます。設定バックアップ／復元にも含まれ、旧設定は位置 0 として読み込みます。

### 改善・修正

- Issue #27 の縦書きルビ列間隔を改善しました。設定した行間を基本に、不足時だけ本文との衝突を避ける間隔を追加します。
- Noto系・ZenMaruGothicの縦書きで、全角コロン／セミコロンとNoto系の半角長音の表示位置を改善しました。
- SDフォント5系統を更新しました。`✓ ✿ ✽ ❖ № ℡` の収録状況はフォントごとに異なります。

### 更新方法と注意

1. [v0.6.3 リリース](https://github.com/ponto1216-ai/crosspoint-jp/releases/tag/yomuka-v0.6.3) から `firmware.bin` をダウンロードします。
2. 更新前に書籍、設定、SDフォントをバックアップします。
3. `firmware.bin` を名前を変えずにSDカードへ置き、端末で **設定 → 本体 → SDカードファームウェア更新** を実行します。
4. 更新中は電源を切ったり、SDカードを抜いたりしません。

`bootloader.bin` と `partitions.bin` は初回書き込み・復旧用、`SHA256SUMS.txt` はダウンロードした配布物の検証用です。通常のSDカード更新では `firmware.bin` を使用します。

詳しい操作は [基本操作・設定・不具合の確認](../basic-operations-ja.md)、フォント導入は [日本語フォントの導入](../cjk-fonts.md) を参照してください。
