# CSSストリーミング修正版 v3

## 変更点
CSSの全ルールをunordered_mapに保持する方式から、対応するセレクター/プロパティをSDの一時ファイルへ逐次保存する方式へ変更。
章生成時は従来のCssSelectorUsageで必要なルールだけを読み込み、同じセレクターは入力順にapplyOverで統合する。複数CSS間の上書きとプロパティ単位の継承は従来と同じ。

CSSキャッシュ版は10から11へ更新。同じセレクターの複数レコードを許すため、旧版が先頭の指定だけを採用してしまう誤読を避ける。PXC6・章キャッシュのデータ形式は変更しない。
旧CSSキャッシュを再構築した本は既存の仕組みで章キャッシュも再生成する。今回はその際の全書籍生成完了マーカーも解除する。

失敗時にはCSS一時ファイルを削除し、成功時だけ公開する。v2の一括生成の厳格なCSS検証・進捗更新を含む。
一部のCSSだけ成功しても全体を完了扱いにしない。空のCSSルールセットは有効。出力レコード数は16bit上限を超えたら安全に中断する。

## 検証済み
- 2200個の未使用セレクターを含む合成CSSを、ルールマップを保持せず保存できた。
- 章で使う2セレクターだけを読み戻し、重複指定、太字解除、傍点解除、余白、文字サイズが従来方式と一致。
- 空CSS、低メモリ、書き込み/seek/rename失敗、未完了オブジェクトの破棄で部分キャッシュを公開しない。
- 既存CSS往復・途中切断・傍点描画テスト成功。テスト用ファイルは実ファイル同様に書き込み位置を進め、読み直す前にseekするよう整備。

ホスト検証に加え、下記のX3/X4実機確認を実施済み。
全セレクターを必要とする章や、使用セレクター走査ができない章では、読み込み側のメモリ制約が残る。書き込み中もパーサ・一時文字列・SDバッファは必要。
