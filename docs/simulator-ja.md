# Yomuka デスクトップシミュレーター

Yomukaの画面をWindows上で確認するためのシミュレーターです。実機への書き込みは行いません。

## 起動方法

リポジトリ直下の次のファイルをダブルクリックします。

- `run-simulator-x3.cmd`: X3（792×528）
- `run-simulator-x4.cmd`: X4（800×480）

初回やソース変更後はビルドのため少し待ちます。ビルドが終わると別ウィンドウにYomukaの画面が表示されます。

## 操作

| キー | 操作 |
| --- | --- |
| ↑ / ↓ | サイドボタン（前 / 次） |
| ← / → | 本体前面の左右ボタン |
| Enter | 選択・決定 |
| Esc | 戻る |
| P | 電源ボタン |
| S | スリープ |

画面内のメニューはマウスクリックでは操作できません。シミュレーターのウィンドウを一度クリックして選択し、上記のキーで操作します。

表示されるボタン案内と実際のキーの対応は、端末種別、画面の向き、ボタン設定によって変わります。

## 確認できること

- X3/X4の画面サイズ差
- 日本語・英語表示、テーマ、縦横の画面向き
- ホーム、設定、ファイル一覧、読書画面などの配置
- Yomuka独自画面と新しく実装した画面
- EPUBを `fs_/books` に置いた場合の表示と画面遷移

IMU、バッテリー、電子ペーパーの残像や更新波形、実機ボタンの電気的な挙動は再現できません。傾き診断画面では表示確認用の固定された正常値を使用します。

## EPUBを入れる場所

リポジトリ直下に `fs_/books` フォルダーを作り、EPUBを入れてからシミュレーターを再起動します。起動時にLinux側の作業領域へ自動コピーされます。
