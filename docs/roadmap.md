# CrossPoint JP / CrossPoint Yomuka ロードマップ

更新日: 2026-07-23
基準: `xtc-large-file-fix` / `v0.2.8.5` + v0.2.9 のキャッシュ表示実装

## 方針

`v0.2.9` までは **CrossPoint JP** として継続する。`v0.3.0` から、正式名称を **CrossPoint Yomuka**、画面上の短い表記を **Yomuka** とする。

CrossPoint Yomuka は、CrossPoint Reader および CrossPoint JP を基盤にした独立コミュニティフォークであり、いずれの公式版でもない。この由来、ライセンス、派生元へのクレジットは名称変更後も維持する。

過去の CrossPoint JP リリース名と告知は変更・削除しない。v0.3.0 の案内で名称変更と継続したプロジェクトであることを明記する。

## 現在地

### 完了済み

- 日本語 EPUB の縦書き、ルビ、縦中横、書籍スタイル、TXT 横書き、XTC の読了位置復帰。
- EPUB の索引・セクション・PNG/JPEG キャッシュの検証、破損時の再構築、進捗表示、物理ボタンによる中断と再開。
- 書籍単位のキャッシュ削除。読書位置、しおり、表示設定、元の EPUB は保持する。
- v0.2.9 対象の読書キャッシュ状態表示。Lyra / Lyra拡張では EPUB ごとに未生成・再開可能・完了をアイコンで表示し、一括生成後は結果件数を表示する。クラシックテーマには追加しない。
- 青空文庫のダウンロード・更新・索引の原子的保存、検証、再試行と HTTPS 時のメモリ対策。
- スクリーンショット、キャッシュ生成中の撮影、スリープ時のゴースト対策、SDカードからのファームウェア更新、Web Flasher 配布基盤。

### 継続して守ること

- 既存キャッシュと保存済み読書データを壊さない。`/.full_cache_complete` がないキャッシュは中断済みで、再開可能な状態として扱う。
- 画像、縦書き、ルビ、長い EPUB、青空文庫、SD 更新など、実機に影響する変更は端末で確認してから出荷する。
- Flash/RAM の削減は、計測と影響調査を先に行う。内蔵 CJK UI フォントや WebUI は、具体的な不足がない限り削除しない。
- `serial.txt` は利用者の端末ログとして扱い、変更・コミットしない。

## v0.3.0 — CrossPoint Yomuka への移行

### 実施範囲

- 表示名を `Yomuka`、正式名称を `CrossPoint Yomuka` にする。
- README、ユーザーガイド、GitHub About、リリースノート、Web Flasher、生成済み WebUI、起動画面・設定画面を同じ方針で更新する。
- v0.3.0 のリリースノートと固定告知に、旧称が CrossPoint JP であることを一度だけ明記する。
- ライセンス、著作権表示、CrossPoint Reader / CrossPoint JP へのクレジット、非公式フォークである説明を確認する。
- 配布ファイル名、OTA、フォント配布 URL、リポジトリ URL は、実際に移転を決めるまで変更しない。名称変更と URL 移転を同じ変更にしない。

### 出荷前に確認すること

- 既存の v0.2.x から更新して、読書進捗、設定、EPUB キャッシュが安全に扱えること。
- OTA 更新確認、SD カード更新、Web Flasher の名称と配布物が一致すること。
- Lyra、Lyra拡張、クラシックのホーム・一覧・読書・設定画面を確認すること。
- 過去リリースと過去の X 告知は残し、新しい告知から利用者が移行を理解できること。

## v0.3.x — 実測に基づく改善

優先するのは、再現できる不具合だけである。候補は次のとおり。

1. 青空文庫のテキスト中心・長大・画像付き作品でのダウンロード、再起動後の索引、読書開始を確認し、失敗作品を個別に修正する。
2. PNG/JPEG 混在 EPUB の画像後ゴースト、大画像、壊れた画像キャッシュを端末ログと実画像で確認し、表示品質を保ったまま直す。
3. 縦書き・横書き、ルビ、書籍スタイル3モード、TXT、XTC の回帰を代表作品で確認する。
4. Flash/RAM と最大連続確保可能領域を再計測する。機能削減は、余白不足と利用者影響が確認できた項目だけを対象にする。

## v0.4.0以降 — 長期保守

- SDカード更新を実機で継続回帰し、失敗時の復旧手順と配布物一覧を整備する。
- スクリーンショットと既存ログを基礎に、必要であれば最小限の診断表示を追加する。
- Web Flasher、リリース自動化、フォント配布を、実際の配布先と利用手順に合わせて保守する。
- リカバリーモード、新端末対応、設定のエクスポート/インポート、先読み、キャッシュ自動削除は、具体的な利用者要求と安全設計がそろうまで保留する。

## 共通の出荷チェック

- PlatformIO の対象ビルド、差分検査、配布物名とバージョンを確認する。
- EPUB の横書き・縦書き・ルビ・画像付き・長大作品、TXT、XTC を端末で確認する。
- キャッシュ生成、中断、再起動、再生成、書籍単位削除を確認する。
- 青空文庫のダウンロード、通信失敗後の再試行、再起動後の索引を確認する。
- SD 更新に変更がある版では、実際の書込みと再起動まで確認する。
